# WDD 430 Web Developer Portfolio

A responsive web developer portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Live Deployment
- **Production URL:** [https://wdd430-portfolio-rho-dusky.vercel.app](https://wdd430-portfolio-rho-dusky.vercel.app)

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Project Structure & Features
- **Server Components:** `Header`, `Footer`, `ProjectCard`, `ProjectList`, and a custom `SkillsCard` component.
- **Routing:**
  - `/` — Portfolio homepage featuring responsive project showcases.
  - `/about` — Background summary and categorized technical competencies.
  - `/api/hello` — Next.js Route Handler demonstrating backend API functionality.
